How does content safety work?
All image requests are filtered under the OpenAI policy.

 

For our GPT Image API, you can opt into stricter review with moderation:"strict". Requests that violate policy will return an error instead of an image.

 

Where are images stored, and for how long?
Images generated by the API are not stored permanently by OpenAI. If you request response_format:"url" the link remains valid for 60 minutes. Always download or cache the file if you need long‑term access.

 

What does it cost?
For more details about pricing, check out our model page.

 

Can I edit only part of an image?
Yes. Supply a mask PNG where the transparent pixels indicate the area to replace. The mask must match the original image’s dimensions.
