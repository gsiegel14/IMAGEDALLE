
# Vexis Image Training Platform

A web application for medical ultrasound synthetic image generation using OpenAI GPT Image and DALL-E 3 APIs.

## Features

- Generate medical ultrasound images using OpenAI's GPT Image and DALL-E 3 APIs
- Upload example images for better context
- Configure image parameters (resolution, style, quality)
- View image generation history
- Batch processing capabilities

## Technologies

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Express.js, Node.js
- API: OpenAI GPT Image and DALL-E 3

## Setup

1. Clone the repository
2. Install dependencies: `npm install`
3. Create a `.env` file with your OpenAI API key: `OPENAI_API_KEY=your_key_here`
4. Start the development server: `npm run dev`
